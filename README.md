## 📖 About The Project

This project was developed as part of my Web Development Internship to demonstrate the implementation of a responsive navigation menu using HTML, CSS, and Bootstrap 5.

The website includes multiple sections such as Home, About, Services, and Contact, allowing users to navigate smoothly through the webpage. The design focuses on simplicity, responsiveness, and a clean user experience across different devices.

---

## 🚀 Features

- ✅ Responsive Navigation Bar
- ✅ Smooth Scrolling Navigation
- ✅ Home Section with Call-to-Action Button
- ✅ Detailed About Section
- ✅ Services Section with Bootstrap Cards

- ✅ Mobile-Friendly Layout
- ✅ Modern User Interface
